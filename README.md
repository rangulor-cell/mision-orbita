# Mision Orbita

Proyecto desarrollado en Python para simular la preparación y validación de una misión espacial.

## Integrante

Josue Angulo

## Archivos del proyecto

- ejercicio1_recursos.py
- ejercicio2_combustible.py
- ejercicio3_tripulacion.py
- ejercicio4_lanzamiento.py

## Descripcion

### Ejercicio 1
Calcula los recursos necesarios para una misión espacial.

### Ejercicio 2
Verifica si existe suficiente combustible para realizar la misión.

### Ejercicio 3
Valida la disponibilidad de oxígeno y provisiones para la tripulación.

### Ejercicio 4
Determina si se autoriza o no el lanzamiento de la misión.

## Ejecucion

Ejemplo:

python ejercicio1_recursos.py
