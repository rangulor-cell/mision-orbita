# Misión Órbita

Proyecto desarrollado en Python para simular la preparación y validación de una misión espacial.

## Integrante

Rachid Josué Angulo Rodríguez

## Descripción de los ejercicios

### Ejercicio 1: Cálculo de recursos

Calcula el combustible, oxígeno, energía y provisiones necesarios para una misión, considerando la cantidad de tripulantes, los días de viaje y las reservas establecidas.

### Ejercicio 2: Verificación de combustible

Calcula el combustible total requerido para llegar, regresar y mantener una reserva de emergencia. También muestra una advertencia cuando el margen adicional es menor que el mínimo establecido.

### Ejercicio 3: Soporte para la tripulación

Verifica mediante una condición compuesta si la nave posee suficiente oxígeno y provisiones para la tripulación.

### Ejercicio 4: Autorización del lanzamiento

Comprueba si el combustible, el oxígeno, la energía y las provisiones son suficientes para autorizar el lanzamiento.

## Archivos del proyecto

- `ejercicio1_recursos.py`
- `ejercicio2_combustible.py`
- `ejercicio3_tripulacion.py`
- `ejercicio4_lanzamiento.py`

## Requisitos

- Python 3
- Terminal, PowerShell o Símbolo del sistema

## Ejecución

Para ejecutar cualquiera de los programas:

```bash
python nombre_archivo.py
```

Si el comando anterior no funciona en Windows, se puede utilizar:

```bash
py nombre_archivo.py
```

Ejemplo:

```bash
py ejercicio1_recursos.py
```

## Convenciones utilizadas

- Variables escritas en `snake_case`.
- Constantes escritas en mayúsculas.
- Indentación de cuatro espacios.
- Programas ejecutados mediante consola.
- Comentarios para identificar entradas, procesamiento, decisiones y salidas.
- No se utilizaron ciclos, listas, diccionarios, funciones propias ni librerías externas.
